# 🏛️ Gabinete Digital - Intranet de Gestão de Demandas

Sistema leve de triagem e CRM interno desenvolvido para assessorias de gabinetes legislativos municipais gerenciarem solicitações de munícipes vindas de múltiplos canais (WhatsApp, Instagram, ligações e presencial).

## 🚀 Funcionalidades
- **Cadastro Multicanal:** Registro de demandas com identificação da origem do contato.
- **Campos Dinâmicos:** Endereço livre (Rua e Bairro) e categorias customizadas (Infraestrutura, Saúde, Educação, etc.).
- **Barra de Busca Instantânea:** Filtragem rápida de registros por nome, rua, bairro, categoria ou número de protocolo.
- **Automação de WhatsApp:** Geração de link dinâmico (`wa.me`) com mensagens personalizadas informando o status atualizado da solicitação ao cidadão.
- **Persistência Local:** Salvamento automático de dados via `localStorage` do navegador, sem necessidade de banco de dados complexo.

## 🛠️ Tecnologias Utilizadas
- **HTML5 & JavaScript Puro (Vanilla JS)**
- **Tailwind CSS (via CDN)**
- **GitHub Pages** (Deploy contínuo)
